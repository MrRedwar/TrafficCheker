# TrafficChecker

TrafficChecker - простое Windows-приложение на Python для базового сбора и
анализа сетевой активности текущего устройства.

Программа не перехватывает содержимое пакетов и не читает передаваемые данные.
Она собирает только техническую картину сетевой активности:

- изменение входящего и исходящего трафика по сетевым адаптерам;
- активные TCP/UDP-соединения;
- процессы, у которых были замечены сетевые сокеты;
- состояния соединений;
- часто используемые удаленные порты;
- понятный анализ наблюдаемой картины.

## Запуск приложения

Самый удобный способ:

1. Откройте папку проекта в Проводнике Windows.
2. Запустите файл `Run-TrafficChecker.cmd`.
3. В окне программы нажмите `Запустить`.
4. Когда нужно завершить наблюдение, нажмите `Остановить`.

Из терминала VS Code:

```console
.\Run-TrafficChecker.cmd
```

Или напрямую через Python:

```console
python traffic_checker_app.py
```

## Консольный режим

Для быстрой проверки без окна:

```console
python traffic_checker_cli.py --duration 60
```

Сбор за 30 секунд с выборкой каждые 3 секунды:

```console
python traffic_checker_cli.py --duration 30 --interval 3
```

Сохранение найденных соединений в CSV:

```console
python traffic_checker_cli.py --duration 60 --csv traffic-report.csv
```

## Запуск через Docker

Docker-режим предназначен для консольного запуска и тестов:

```console
docker build -t traffic-checker .
docker run --rm traffic-checker
```

С другой длительностью сбора:

```console
docker run --rm traffic-checker python traffic_checker_cli.py --duration 30 --interval 3
```

С VirusTotal:

```console
docker run --rm -e VT_API_KEY="ваш_ключ" traffic-checker
```

Важно: контейнер видит сетевую активность внутри контейнера, а не весь трафик
Windows-хоста. Для анализа именно текущего компьютера удобнее запускать обычное
Windows-приложение через `Run-TrafficChecker.cmd`. На Linux можно добавить
`--network host`, но на Docker Desktop для Windows это не превращает контейнер в
полноценный монитор всего трафика Windows.

## Что показывает программа

Вкладка `Анализ` обновляется во время сбора и объясняет, что происходит:

- сколько соединений замечено;
- сколько из них внешние, а сколько внутренние/служебные;
- какой сетевой адаптер сейчас передает больше всего данных;
- какие процессы чаще всего видны во внешнем трафике;
- на какие сайты или домены удалось сопоставить удаленные IP через DNS-кэш Windows;
- кому принадлежат IP-диапазоны через RDAP/WHOIS;
- встречались ли сайты/IP в публичном списке malware-хостов URLhaus;
- какие внешние порты используются;
- есть ли состояния, на которые стоит обратить внимание, например
  `CLOSE_WAIT` или большое количество коротких соединений.

Остальные вкладки по умолчанию показывают внешний трафик, чтобы локальные
служебные соединения Windows не мешали анализу. Если нужны все соединения,
включите флажок `Показывать внутренние`.

Вкладка `Сессии` показывает время первого и последнего наблюдения сессии, а
также количество повторных наблюдений во время сбора.

Вкладка `Сайты` группирует внешние сессии по предполагаемому сайту/домену,
процессу и порту. Если домен не найден в DNS-кэше Windows, программа показывает
сам IP-адрес. Это приближение: один IP может принадлежать CDN или облаку и
обслуживать несколько сайтов.

Вкладка `Владельцы IP` показывает владельцев сетей по RDAP. Это помогает понять,
что неизвестный IP относится, например, к облаку, CDN, игровому сервису или
провайдеру приложения. RDAP-запросы выполняются в фоне и могут не заполниться,
если нет доступа в интернет или сервис не ответил.

Вкладка `Безопасность` проверяет сайты и IP по публичному списку malware-хостов
URLhaus. Программа загружает список один раз во время работы и сравнивает с ним
наблюдаемые домены/IP. Статус `Не найдено в базе угроз` означает только то, что
совпадений в URLhaus не найдено. Это не абсолютная гарантия безопасности.
Статус `Опасно` требует ручной проверки.

Дополнительно можно включить проверку через VirusTotal. Для этого нужен личный
API-ключ VirusTotal. Самый безопасный способ - задать его через переменную
окружения `VT_API_KEY`, например в PowerShell:

```powershell
$env:VT_API_KEY = "ваш_ключ"
.\Run-TrafficChecker.cmd
```

Если `VT_API_KEY` не задан, приложение продолжит работать через URLhaus и в
деталях проверки покажет, что VirusTotal не настроен. VirusTotal может иметь
лимиты запросов, поэтому проверка выполняется постепенно.

Для VirusTotal программа показывает не только общий статус, но и рейтинг риска.
Например, если найдено 1 срабатывание и много безопасных отметок, запись будет
помечена как `Подозрительно` / `Низкий риск`, а в деталях будет видно количество
срабатываний и безопасных отметок. `Опасно` используется для более уверенных
случаев: несколько malicious-срабатываний или много суммарных malicious/suspicious
отметок.

Также программа умеет читать ключ из локального файла
`traffic_checker.local.json`. Этот файл добавлен в `.gitignore`, поэтому он не
должен попасть в GitHub. Для примера рядом есть шаблон
`traffic_checker.local.example.json` без настоящего ключа.

Оконное приложение работает в ручном режиме: сбор начинается кнопкой
`Запустить` и завершается кнопкой `Остановить`.

## Структура проекта

- `traffic_checker_core.py` - сбор данных, группировка, анализ и экспорт CSV.
- `traffic_checker_app.py` - оконное приложение на `tkinter`.
- `traffic_checker_cli.py` - консольный запуск для отладки.
- `Run-TrafficChecker.cmd` - простой запуск приложения на Windows.
- `Dockerfile` - консольный запуск в контейнере.

## Приватность

CSV-отчеты не должны попадать в репозиторий. Для этого в `.gitignore` добавлено
правило `traffic*.csv`.

Текущая версия не сохраняет данные автоматически. CSV создается только если
пользователь нажмет кнопку сохранения или укажет путь через консольный режим.

## Ограничения

Windows не дает точные байты по каждому процессу через используемые здесь
стандартные средства. Поэтому таблица процессов показывает количество
замеченных сетевых сокетов, а не точный объем трафика каждого процесса.
