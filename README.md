# TrafficChecker

Простое Windows-приложение для базового сбора и анализа сетевой активности
текущего устройства.

На первом этапе программа не перехватывает содержимое пакетов и не читает
передаваемые данные. Она собирает только техническую картину сетевой активности:

- изменение входящего и исходящего трафика по сетевым адаптерам;
- активные TCP/UDP-соединения;
- процессы, у которых были замечены сетевые сокеты;
- состояния соединений;
- часто используемые удаленные порты;
- понятный анализ наблюдаемой картины.

## Запуск

Самый удобный способ:

1. Откройте папку проекта в Проводнике Windows.
2. Запустите файл `Run-TrafficChecker.cmd`.
3. В окне программы выберите время анализа и нажмите `Запустить`.

Из терминала VS Code можно запустить так:

```powershell
.\Run-TrafficChecker.cmd
```

Также приложение можно открыть напрямую:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\traffic-checker-app.ps1
```

## Что показывает программа

Вкладка `Анализ` обновляется во время сбора и объясняет, что происходит:

- сколько соединений замечено;
- какой сетевой адаптер сейчас передает больше всего данных;
- есть ли внешние подключения;
- какие процессы чаще всего видны в сети;
- какие процессы подключаются к внешним адресам;
- какие внешние порты используются;
- есть ли состояния, на которые стоит обратить внимание, например
  `CLOSE_WAIT` или большое количество коротких соединений.

Остальные вкладки показывают сырые таблицы: адаптеры, процессы, состояния,
порты и список соединений.

## Консольный режим

Для отладки оставлен консольный скрипт. Сбор за одну минуту:

```powershell
.\traffic-checker.ps1
```

Сбор за 30 секунд:

```powershell
.\traffic-checker.ps1 -DurationSeconds 30 -IntervalSeconds 3
```

Сохранение найденных соединений в CSV:

```powershell
.\traffic-checker.ps1 -DurationSeconds 60 -CsvPath .\traffic.csv
```

## Приватность

CSV-отчеты не должны попадать в репозиторий. Для этого в `.gitignore` добавлено
правило `traffic*.csv`.

Текущая версия не сохраняет данные автоматически. CSV создается только если
пользователь нажмет кнопку сохранения или укажет путь через консольный режим.

## Ограничения

Windows не дает точные байты по каждому процессу через используемые здесь
стандартные средства. Поэтому таблица процессов показывает количество
замеченных сетевых сокетов, а не точный объем трафика каждого процесса.
